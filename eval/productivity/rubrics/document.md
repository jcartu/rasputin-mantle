# Document quality rubric

Score 0-10 for the usefulness and polish of the produced document.

- 9-10: Document is coherent, well formatted for the requested style, contains all requested sections with substantive prose, uses tables or a table of contents where appropriate, and reads like a deliverable ready for its intended audience.
- 7-8: Covers the requested sections with understandable content and acceptable formatting, with only minor gaps or generic phrasing.
- 5-6: Document is structurally present but sparse, repetitive, weakly formatted, or only partly suited to the requested business/academic/minimal style.
- 3-4: Missing major sections, poor organization, incoherent prose, absent requested tables/TOC, or content that is too thin to be useful.
- 0-2: Not a usable document for the prompt.

Do not reward a file that only lists headings. Judge whether the content would actually help the reader complete the requested work.
